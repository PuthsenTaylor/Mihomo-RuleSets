# Mihomo-RuleSets

自建 Mihomo Rule Set 合集：每份文件由多位常见作者的公开清单全量合并求全集，
零自建（每条规则须有作者出处）、集内排序（精确 → 后缀由细到宽 → 关键词 →
IP 由窄到宽）、集内去冗余（被自家宽条目盖住的条目删除）。
